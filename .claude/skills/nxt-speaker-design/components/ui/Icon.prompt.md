One-line: Lucide icon wrapper — the app's only icon system; requires the Lucide UMD script on the page.

```html
<script src="https://unpkg.com/lucide@0.454.0/dist/umd/lucide.min.js"></script>
```
```jsx
<Icon name="search" size={16} />
<Icon name="calendar-check" size={20} color="var(--color-secondary)" />
```

Never substitute emoji, unicode glyphs or hand-drawn SVG for an icon.
